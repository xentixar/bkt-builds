Install bkt the easy way

Installs bkt to ~/.local/bin (Mac/Linux) or %USERPROFILE%\.local\bin (Windows).

Copy the installation command:
/bin/bash -c "$(curl -fsSL https://xentixar.github.io/bkt-builds/install/mac)"
  1. Open Terminal (Spotlight: ⌘ Space → type Terminal → Return).
  2. Paste the command and press Return.
Copy the installation command:
/bin/bash -c "$(curl -fsSL https://xentixar.github.io/bkt-builds/install/linux)"
  1. Open your terminal.
  2. Paste the command and press Enter.
Copy the installation command (PowerShell):
irm https://xentixar.github.io/bkt-builds/install/windows.ps1 | iex
  1. Open PowerShell (Run as user is fine).
  2. If execution policy blocks scripts, run once: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  3. Paste the command and press Enter.
After install
bkt version
bkt auth login --app-password
