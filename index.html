bkt builds

Drop build executables into dist/ on the gh-pages branch. Then download them via this site.

Downloads

  • Browse dist/ directory

How to publish a new build

git clone git@github.com:xentixar/bkt-builds.git
cd bkt-builds
git checkout gh-pages
cp /path/to/bkt-* ./dist/
git add dist/
git commit -m "Add builds"
git push origin gh-pages
